## 📦 Список Плагинов

### 1. `Customoji` (Смерть Telegram Premium)
> *«Зачем платить Дурову $5 в месяц, если можно просто перехватить методы проекции сообщений?»*

Превращает любые нищие ссылки вида:
- `🌟(tg://emoji?id=4909017013667497836)`
- `[🌟](tg://emoji?id=4909017013667497836)`
- `tg://emoji?id=4909017013667497836`

в **настоящие, сочные, интерактивные Telegram Premium эмодзи** прямо в чатах. Полный нативный обход через JNI и мост MandaGram FFI.

#### Установка:
1. Заходишь в папку `Customoji/`
2. Хватаешь `Customoji.dll` (или `.so` если ты красноглазый линуксоид)
3. Закидываешь в папку `plugins/` твоего клиента
4. Заходишь в настройки -> Плагины -> Включаешь и флексишь
