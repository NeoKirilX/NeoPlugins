## 📦 Список Плагинов

### 1. `exmoji` — НЕ ЭКСТЕРА ЭМОДЗИ А ЭМОДЗИ БЫВШЕГО
> *«НЕ ЭКСТЕРА ЭМОДЗИ А ЭМОДЗИ БЫВШЕГО! И вообще, зачем платить Дурову $5 в месяц, если можно просто перехватить методы проекции сообщений?»*

Превращает любые нищие ссылки вида:
- `🌟(tg://emoji?id=4909017013667497836)`
- `[🌟](tg://emoji?id=4909017013667497836)`
- `tg://emoji?id=4909017013667497836`

в **настоящие, сочные, интерактивные Telegram Premium эмодзи** прямо в чатах. Полный нативный обход через JNI и мост MandaGram FFI.

#### Установка:
1. Заходишь в папку `exmoji/`
2. Хватаешь `exmoji.dll` (или `.so` если ты красноглазый линуксоид)
3. Закидываешь в папку `plugins/` твоего клиента
4. Заходишь в настройки -> Плагины -> Включаешь и флексишь

### 2. `mathtab` — Инлайн-Калькулятор для Быстрых Разборок
> *«Зачем сворачивать клиент и открывать калькулятор, если можно считать прямо во время спора в чате?»*

Превращает обычную строку ввода сообщений в умный интерактивный калькулятор с полупрозрачным автодополнением в стиле iOS:
- **Полупрозрачная подсказка** — пока ты пишешь пример (например, `2+2`), плагин на лету считает результат и показывает его серым полупрозрачным текстом сразу за курсором (`=4`).
- **`Tab`** — дописывает знак равенства и решение к примеру: `2+2` ➔ `2+2=4`. Нажатие Tab на уже решенном примере блокируется, так что спама не будет.
- **`Alt+Tab` (или `Shift+Tab`)** — полностью заменяет весь пример на итоговый ответ: `2+2` ➔ `4`.
- **Удержание `Alt`** — на лету показывает превью чистого ответа прямо на месте примера.
- **Цепочки вычислений** — умеет считать продолжения вида `2+2=4-3` ➔ по Tab допишет `=1`, по Alt+Tab оставит `1`.
- **Алгебраические уравнения** — решает линейные и нелинейные уравнения с одной переменной: `2x+4=10` ➔ по Tab допишет `(x=3)`, по Alt+Tab оставит `x=3`.
- **Координаты и векторная геометрия** — сложение и вычитание точек `(10, 20) + (5, 30)` ➔ `(15, 50)`, умножение на скаляр `(10, 20) * 2` ➔ `(20, 40)`, скалярное произведение `dot`, расстояние `dist(0, 0, 3, 4)` ➔ `5`, гипотенуза `hypot`, середина отрезка `mid`, длина вектора `len`.
- **Инженерная математика** — корни `sqrt`, `cbrt`, тригонометрия `sin`, `cos`, `tan`, логарифмы `ln`, `log`, `log2`, степени `^`, проценты `%`, константы `pi` (`пи`), `e`.
- **Полная неубиваемость** — иммунитет к русскому тексту (`ывфыв2+2`), опечаткам, эмодзи (`👋 2+2`) и делению на ноль без крашей клиента.

#### Установка:
1. Заходишь в папку `mathtab/`
2. Хватаешь `MathTab.dll` (или `.so` если ты красноглазый линуксоид)
3. Закидываешь в папку `plugins/` твоего клиента
4. Заходишь в настройки -> Плагины -> Включаешь и считаешь быстрее всех
